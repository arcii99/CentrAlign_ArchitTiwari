# AP Tracker Guide (AP/AP_Tracker.xlsx)

The tracker is the AP team's log: one row per invoice handled, in the sheet "Invoices". Add new rows at the
bottom. Never edit or delete existing rows; to correct a mistake, add a new row with a note.

| Column | Content |
|---|---|
| Date Processed | DD-MM-YYYY |
| Vendor | Vendor legal name |
| Vendor Invoice No | As on the invoice |
| Invoice Date | DD-MM-YYYY |
| PO No | PO number, or blank |
| Invoice Total | Number, no currency symbol |
| TDS | Number (0 if none) |
| Net Payable | Number |
| Bill ID | Finance Portal bill ID, or blank |
| Payment ID | Finance Portal payment ID, or blank |
| Payment Date | DD-MM-YYYY, or blank |
| Status | One of the values below |
| Notes | Anything a colleague would need to know |

Status values:

- Payment Scheduled
- On Hold - PO Mismatch
- On Hold - Unknown Vendor
- Duplicate - Already Paid
- Duplicate - Refund Requested
- Paid (historical rows)
